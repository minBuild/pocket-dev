## 구현 시 주의 (명세 우선)

Stitch 결과물에는 명세에 없는 장식이 섞여 있다(예: "실시간 동기화" 배지, 브라우저 창 프레임·LIVE 표시, 1 vs 1 투표 바, "Chrome 작업 재시도" 버튼, 퀵 칩, 커밋 해시·PR 번호 예시). 이들은 **무시**한다. 명세(TASK_SPEC.md)의 범위 밖이다(실시간 영상, "Chrome 단계만 다시" 버튼 등). 표시 문자열은 `describe()["text"]` 하나만 쓴다.
