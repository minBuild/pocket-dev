## 구현할 때 주의

Stitch 시안에는 TASK_SPEC §6 에서 뺀 요소가 섞여 있다. 구현에서는 넣지 않는다.
- LIVE 배지, 브라우저 창 프레임, 일시중지/재시도 버튼
- `run-history` 시안의 진행률 게이지, 소요 시간·커밋 수, 하단 탭 바(Agents/Logs/Diffs/Console), 날짜 머리글
- `chrome-overlay` 시안의 부제목, `○ 👁 대기` 같은 예정 단계 줄(단계 목록은 실제 일어난 동작만)
- 새 색상 변수·애니메이션·새 시트는 추가하지 않고 기존 `web/style.css` 변수(`--line`, `--bg`, `--muted` 등)를 쓴다.
- 시안의 hex 값보다 기존 앱의 변수가 우선이다.

### 글꼴

- 본문·제목: Inter (한글은 Pretendard 대체). 본문 14px/20px, 작은 글자 13px/18px, 제목 18px 600 (headline-md), 라벨 12px 500
- 시각·좌표·배지·코드: JetBrains Mono 10~13px
- 한글 본문 줄 높이는 글자 크기의 1.45~1.5배

### 간격·모양

- 8px 격자(보조 4px), 화면 좌우 여백 16px, 카드 안쪽 12~16px
- 카드 12px 둥글기, 버튼·입력 8px, 배지·필 4px(상태 점만 완전 원형)
- 스크린샷 카드 16:10, 둥글기 4px, 1px 테두리
- 높이 구분은 그림자 대신 톤 차이와 1px 테두리. 시트만 그림자 `0 12px 32px -4px rgba(0,0,0,0.65)`
- 버튼 높이 44px, 하단 입력창 48px 이상
