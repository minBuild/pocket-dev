## 디자인 토큰

실제 앱 `web/style.css`의 CSS 변수가 기준입니다. Stitch 시안의 Material 팔레트(`#0b1420` 등)와 일부 값이 다르니 시안 값이 아니라 아래 변수를 쓰세요.

| 변수 | 다크 | 라이트 | 용도 |
|---|---|---|---|
| `--bg` | `#0f1115` | `#f6f7f9` | 화면 배경 |
| `--card` | `#181b21` | `#fff` | 카드·말풍선 바탕 |
| `--text` | `#e6e8eb` | `#1d2129` | 본문 |
| `--muted` | `#9aa1ab` | `#6b7280` | 보조 글씨·chat_action 줄 |
| `--line` | `#2a2f37` | `#e5e7eb` | 테두리·구분선 |
| `--accent` | `#60a5fa` | `#2563eb` | 버튼·사용자 말풍선 틴트·링크 |
| `--danger` | `#f87171` | `#dc2626` | 🔒 불일치·⛔·거부 |
| `--ok` | `#34d399` | `#059669` | ✅ 허용 계정 |

경고(⚠️ 결과 카드 제목)용 색은 변수가 없어 시안의 앰버(`#fbbf24`)를 참고합니다. 구현 때 기존 경고 색이 있으면 그걸 씁니다.

- 글꼴: 시안은 Inter(본문)와 JetBrains Mono(로그·이메일). 앱은 기존 글꼴 스택을 유지합니다.
- 간격: 4/8px 격자. 화면 여백 16px(로그 화면 12px), 카드 안 여백 16px.
- 모양: 카드 12px, 버튼·입력 8px, 칩 높이 24px.
- 명세 컴포넌트 규칙(§3.11):
  - `.msg.user`는 채운 말풍선 — `color-mix(in srgb, var(--accent) 14%, var(--card))`, 왼쪽 선 accent, `margin-left: 12%`.
  - `.msg.result`는 투명 바탕 + 점선 테두리.
  - `.thread`는 왼쪽 2px `--line`, 안쪽 여백 8px, 아래 간격 10px.
  - `.chat-action`, `.bstep.account`는 글자색 `--text`.
