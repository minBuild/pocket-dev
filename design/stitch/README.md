## 구현할 때 주의

Stitch 시안에는 TASK_SPEC §6 에서 뺀 요소가 일부 들어갈 수 있다. 구현에서는 넣지 않는다.
- LIVE 배지, 브라우저 창 프레임, 재시도 버튼
- 칩 아래 빠른 응답 칩, 터미널 로그 카드, 필터 탭 같은 시안 장식. 기존 화면에 없는 것은 따라 하지 않는다.
- 새 색상 변수·애니메이션은 추가하지 않고, 기존 `web/style.css` 변수(`--line`, `--bg` 등)를 쓴다.
